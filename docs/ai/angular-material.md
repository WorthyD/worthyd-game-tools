# Angular Material / CDK

Installed: **@angular/material and @angular/cdk 21.2**, M3 theming.

## Where themes live

| App | Theme |
|---|---|
| `craft-cart` | `apps/craft-cart/src/styles/material.scss` — `mat.theme()` (light, azure/blue) |
| `destiny-clan-dashboard` | `apps/destiny-clan-dashboard/src/theme/` (imported from `styles.scss`), plus component and utility partials |
| root | `m3-theme.scss` — palettes generated by `ng generate @angular/material:m3-theme`; don't hand-edit |

Change a theme in its theme file only, never inside component styles.

## Theming rules (M3)

- `mat.theme((color: (...), typography: ..., density: ...))` emits **system variables** such as
  `--mat-sys-primary`, `--mat-sys-on-primary`, `--mat-sys-surface`, `--mat-sys-surface-container`,
  `--mat-sys-on-surface`, `--mat-sys-outline`, `--mat-sys-error`, `--mat-sys-corner-medium`,
  `--mat-sys-body-medium`. Use them in custom styles instead of hard-coded colors.
- Customize components with their **overrides mixins** in the theme file:

  ```scss
  @include mat.button-overrides((filled-container-shape: 8px));
  @include mat.card-overrides((elevated-container-color: var(--mat-sys-surface-container-low)));
  @include mat.form-field-overrides((filled-container-color: var(--mat-sys-surface-container)));
  ```

- **Don't** target `.mdc-*` / `.mat-mdc-*` internals or use `::ng-deep` in new code. DCD's global
  `styles.scss` has a few legacy selectors like that; leave them, don't add more.
- No M2 APIs (`mat.define-light-theme`, `mat.core()`, theme maps) in new code.

## Using components

- Import specific modules in the standalone component (or DCD NgModule): `MatButtonModule`,
  `MatCardModule`, `MatFormFieldModule`, `MatInputModule`, `MatSelectModule`, `MatTableModule`,
  `MatSortModule`, `MatPaginatorModule`, `MatDialogModule`, `MatIconModule`,
  `MatProgressSpinnerModule`, `MatSidenavModule`, …. No catch-all "MaterialModule".
- Buttons: `mat-flat-button`, `mat-stroked-button`, `mat-button`, `mat-icon-button` (the style
  used across the repo).
- Form fields: `<mat-form-field>` + `<mat-label>` + `matInput`/`mat-select`, `<mat-error>` for
  messages. `subscriptSizing: 'dynamic'` is the app default in Craft Cart.
- Tables (DCD has many): `mat-table` + `MatSort` + `MatPaginator` via `viewChild()`; give the data
  source stable identity; prefer `cdk-virtual-scroll-viewport` for very long lists.
- Icons: DCD registers SVG icons via `registerIcons()` from `@dcd/shared/ui/icons` with
  `MatIconRegistry`; add new DCD icons there and use `<mat-icon svgIcon="name">`. Ligature icons
  (`<mat-icon>cancel</mat-icon>`) are also used. Decorative icons get `aria-hidden="true"`;
  icon-only buttons need `aria-label`.

## Dialogs / snack bars

```ts
private readonly dialog = inject(MatDialog);

openError(error: SearchError) {
  this.dialog
    .open<SearchErrorDialogComponent, SearchError, boolean>(SearchErrorDialogComponent, { data: error })
    .afterClosed()
    .subscribe((retry) => { if (retry) this.retry(); });
}
```

Inside: `readonly data = inject<SearchError>(MAT_DIALOG_DATA);` and
`readonly ref = inject<MatDialogRef<SearchErrorDialogComponent, boolean>>(MatDialogRef);`.
Dialogs live in their own `ui` lib (see `@dcd/clan-search/ui/search-error-dialog`). Use
`mat-dialog-title`, `mat-dialog-content`, `mat-dialog-actions`, `mat-dialog-close`.

## Testing with harnesses

```ts
const loader = TestbedHarnessEnvironment.loader(fixture);
const add = await loader.getHarness(MatButtonHarness.with({ text: 'Add' }));
await add.click();
const select = await loader.getHarness(MatSelectHarness);
await select.clickOptions({ text: 'Iridium' });
```

Overlays (dialogs, selects, menus): `TestbedHarnessEnvironment.documentRootLoader(fixture)`.

## Material + Tailwind (Craft Cart)

- Material owns component internals; Tailwind owns layout and spacing around them.
- In `craft-cart`, the build loads `styles/tailwind.scss`, then `styles/material.scss`, then
  `styles.scss` — keep that order.
- Use Tailwind colors mapped to `--mat-sys-*` (see `tailwind.md`) so both share one palette.
