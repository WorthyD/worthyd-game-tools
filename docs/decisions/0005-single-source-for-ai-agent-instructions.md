# One source for AI agent instructions, generated per tool

## Context and Problem Statement

The repo is used with both Claude Code and GitHub Copilot. Each reads instructions from different
files with different frontmatter (`CLAUDE.md` and `.claude/rules/` with `paths`;
`.github/copilot-instructions.md` and `.github/instructions/` with `applyTo`). Hand-maintaining both
sets would let them drift apart.

## Considered Options

- One source (`AGENTS.md`, `docs/ai/`, `docs/decisions/`) plus a generator
- Hand-maintain each tool's files
- `AGENTS.md` only, with no path-scoped guides

## Decision Outcome

Chosen option: "One source plus a generator", because both tools get the same guidance, path-scoped
guides keep context small, and CI catches drift.

- Edit `AGENTS.md` (outside the generated ADR index block), `docs/ai/*.md` and `docs/decisions/*.md`.
- Never edit `.github/copilot-instructions.md`, `.github/instructions/*` (except Nx Console's own
  `nx.instructions.md`) or `.claude/rules/*` by hand. Run `npm run ai:sync` and commit the sources
  and generated files together.
- `CLAUDE.md` stays a thin file that imports `AGENTS.md`.

### Consequences

- Good: Claude Code and Copilot get the same rules.
- Bad: contributors must remember to run the sync; CI reminds them.

### Confirmation

The `ai-instructions.yml` workflow runs `node tools/ai/sync-ai-rules.mjs --check` on PRs.
